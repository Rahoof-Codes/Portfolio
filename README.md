## 🚀 Key Dynamic Features

- 🤖 **Interactive Multi-Agent Lab**: Live interactive simulator running a 4-Agent LangGraph pipeline (Search → Summarize → Write → Bedrock Guardrails) with real-time execution telemetry and verified report synthesis.
- ⚡ **Spotlight Command Palette (`Ctrl+K` / `⌘K`)**: Instant search and navigation across sections, projects, and developer actions.
- 💻 **Interactive Developer Terminal (`>_`)**: Toggleable retro-cyber CLI drawer supporting commands like `help`, `whoami`, `skills`, `projects`, `sudo hire` (Easter egg 🎉), and `theme`.
- 💬 **Next-Gen J.A.R.V.I.S HUD Assistant**: Floating AI assistant with sound-wave audio visualizer, memory state indicators (Redis STM / pgvector LTM), and streaming responses.
- 🌌 **Neural Canvas Background**: Dynamic interactive node network that reacts smoothly to mouse gestures with hardware acceleration.
- 🗂️ **Projects Gallery & Lightbox Modal**: Real-time project search and filtering by category (`AI & ML`, `Full Stack`, `Frontend`, `Tools & POS`) with deep-dive architectural modals.
- 🟢 **Live Telemetry Strip**: Real-time Indian Standard Time (IST) clock, AWS cluster latency indicator, and availability status.
- 🌓 **Theme Switcher**: Smooth transitions between deep cyber dark mode and high-contrast light mode.
